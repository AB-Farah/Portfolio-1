# Portfolio Project 1 - Software Development

## Project Description

This portfolio is about object-oriented programming and software engineering, focusing on implementing classical OOP models and understanding, applying, and ensuring software requirements.

It is the first of three parts that should be submitted for the exam as a mini-project.

## Assignment Description

Develop an object-oriented tool for registering students for activities in their bachelor programme.

The assignment consists of the following parts:

1. Make a Kanban board for this assignment.
2. Make a class diagram for the bachelor programme and its components.
3. Implement classes to represent the bachelor programme and its components.
4. Create a method that prints the completion status of a bachelor's programme.
5. Specify and run unit tests for the creation of project groups.

## Programme Model

The assignment uses a simplified model of bachelor's programmes at Roskilde University.

A bachelor's programme for a given student consists of several study activities, which are either courses or projects. Activities have unique names and an ECTS value.

Study activities belong to either a basic studies programme (HumTek, NatBach, HumBach, SamBach) or to subject modules.

## Project Groups

When students have signed up for a project, they should also form a project group with other students, write a project title, and specify a supervisor.

For a student, there can be at most one project group for each project activity in their programme, and all students in the group must be signed up for that activity.

## Completion Requirements

A completed bachelor's programme for a student must consist of:

- 110 ECTS of activities from a basic studies programme.
- 35 ECTS from each of two subject modules.
- Membership of a project group for every project activity in the student's programme.

## Scope

Only a simplified model of study programmes is considered. There are no elective courses, exchange programmes, study board to allocate supervisors, exams, or integrated projects across different programmes.
